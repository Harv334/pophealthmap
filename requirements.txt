# Pinned so a scheduled refresh cannot break on an upstream release.
# Versions match what the pipeline is developed and tested against.
# Python 3.11 or newer.
#
# Every entry below is imported by fetch_all_data.py. pyproj and shapely are
# imported lazily, inside the functions that need them, so an import error
# surfaces only when a geometry-dependent source runs.
#
#   pandas   dataframes, every source
#   pyarrow  parquet engine used by pandas (no direct import)
#   requests every HTTP call
#   shapely  point-in-polygon for crime and terminated-postcode placement
#   pyproj   British National Grid to WGS84 conversion
#   openpyxl the .xlsx reader pandas dispatches to (no direct import)
#
# openpyxl is the reason to read the note above about indirect dependencies.
# DESNZ publish sub-regional fuel poverty as .xlsx and nothing else, so
# pd.ExcelFile and pd.read_excel are the only way in, and pandas hands both to
# openpyxl without importing it itself. It was never listed, so the fuel poverty
# fetch failed on every scheduled run with ImportError while the other fifteen
# sources succeeded: the pipeline reported "ok" overall and the map served
# figures that had quietly stopped refreshing.
